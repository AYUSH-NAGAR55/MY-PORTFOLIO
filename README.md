# Ayush Nagar — Portfolio

A personal portfolio site built to showcase my work as a Computer Science undergraduate specializing in Cyber Security — full-stack development, applied machine learning, and secure systems.

🔗 **Live site:** [ayush-nagar55.github.io/MY-PORTFOLIO](https://ayush-nagar55.github.io/MY-PORTFOLIO/) <!-- update if the deployed URL changes -->

## About

This is a single-page portfolio covering:

- **Hero** — an animated, cursor-reactive network diagram (nodes/edges), nodding to my cyber security specialization
- **About** — a short profile summary
- **Skills** — languages, frameworks, databases, cyber security tools, and core CS concepts
- **Experience** — internships at MP Police (State Cyber Cell) and Hackveda Pvt. Ltd.
- **Projects** — XAI-IDS (explainable intrusion detection), a full-stack CMS, and an AI voice assistant
- **Education** — B.Tech, Computer Science (Cyber Security), Oriental College of Technology, Bhopal
- **Contact** — email, GitHub, and phone, with a one-tap copy fallback

## Tech Stack

- **HTML5 / CSS3** — single static file, no build step
- **Vanilla JavaScript** — scroll animations, 3D hover tilt on project cards, and a canvas-based particle/network animation in the hero
- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono

No frameworks, no dependencies, no build process — just one `index.html` file.

## Accessibility & Performance

- Respects `prefers-reduced-motion` — all animations disable for users who request it
- Keyboard-navigable with visible focus states
- No external JS dependencies beyond Google Fonts, so it loads fast
